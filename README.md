# SportClubFitLine
# FitLine — сайт женского спортивного клуба (учебная практика)

Учебный проект, выполненный в рамках учебной практики (3 курс, специальность «Разработчик»): адаптивный сайт женского спортивного клуба **FitLine** с несколькими страницами, стилизацией на CSS (Grid/Flexbox/переменные/медиазапросы) и интерактивом на JavaScript.

---

О проекте

Сайт включает 3 страницы:

- Главная (`index.html`) — описание клуба, преимущества, отзывы, галерея, контакты, форма заявки.
- Тренеры (`trainers.html`) — карточки тренеров и раздел со специализациями.
- Абонементы (`abonements.html`) — варианты абонементов с описанием и кнопками записи.

---

Задание на практику

В рамках практики требовалось:

1. Создать стилевое оформление сайта с использованием CSS Grid, Flexbox, медиазапросов и переменных**  
2. Сверстать главную и две внутренние страницы с адаптивной структурой и семантической HTML-разметкой  
3. Создать форму регистрации/заявки с полной стилизацией, валидацией и интерактивными подсказками  
4. Реализовать динамические элементы на JavaScript: галерея (фильтрация/зум/прокрутка/анимации)**  
5. Разработать UX-прототип в Figma (навигация и сценарии)  
6. Подготовить и оптимизировать изображения (логотип/иконки/баннеры) под web и Retina  
7. Проанализировать целевую аудиторию, выбрать стиль, сделать moodboard и UI-kit с обоснованием  
8. Создать GIF/анимацию (баннер) в стиле сайта  
9. Разработать цветовую схему и графику интерфейса + обоснование (психология цвета)  
10. Создать wireframe-макеты (принципы эргономики и эстетики)  
11. Интегрировать мультимедиа и обеспечить оптимизацию/доступность

---

Технологии

- HTML5 — семантическая разметка, многостраничность
- CSS3
  - переменные `:root`
  - Flexbox для навигации/секций/карточек
  - Grid для галереи
  - адаптив через медиазапросы
- JavaScript (Vanilla JS)
  - мобильное меню (открытие/закрытие)
  - слайдер отзывов (Swiper)
  - валидация формы + вывод сообщений
  - маска телефона `+7 (___) ___-__-__`
  - управление видео (автоплей/пауза через IntersectionObserver, если видео есть на странице)

---

Функциональность

Форма
- проверка обязательных полей
- проверка email
- обязательное согласие (checkbox)
- сообщение об успешной отправке и очистка формы

Галерея
- сетка на CSS Grid
- эффект зума при наведении (hover)

Адаптивность
Поддержка десктопа/планшета/мобильных устройств (адаптив через медиазапросы).
